# Level 3·4 기기별 프레임·글자 맞춤 (2026-10-31)

## 원인과 수정

- 기기별 고정 폰트·높이·확대 규칙이 겹쳤고, 이전 이름 맞춤 처리가 회전 후 다시 커지지 않았다. `responsive-board.js`가 실제 칸 너비·높이와 텍스트 크기를 측정해 이름·아이콘 크기와 가로/세로 배치를 다시 계산한다. 크기·내용별 결과는 캐시하고 폰트 로딩, 보드·헤더 크기, 화면 회전에 맞춰 갱신한다.
- PC의 넓은 화면도 터치 기기와 동일하게 가로 보드를 사용한다. 회전 시 보드 좌표와 말 위치는 기존 방향 변환 함수를 그대로 사용한다.
- 앱 높이는 실제 보이는 화면에 맞추고, 상단과 보드의 폭을 동기화한다. 프레임 크기 전환 애니메이션을 없애고 중앙 고정 확대값을 정리했다.
- 이동 주사위 옆의 좁은 실행 버튼, 보조 버튼, 판정 미리보기, 정세 칩에 줄바꿈과 최소 폭 규칙을 적용했다. 긴 내용은 보드 중앙 안에서 세로로 스크롤한다.
- Level 4 스킨의 큰 배경 장식과 배경 애니메이션이 수백 픽셀의 가로 스크롤 영역을 만들던 문제를 보정했다.
- `dual-dice.css`에 남아 미디어 쿼리를 깨뜨리던 미완성 선택자를 제거하고 캐시 버전을 올렸다.
- 이전 상단 주사위 중복 제거를 유지한다. 게임 규칙·난수·이동/판정 기능은 변경하지 않는다.

## 검증

Chrome의 실제 브라우저 실행에서 같은 게임을 아래 화면 크기로 바꾸어 확인했다. Level 3 주식 선택 메뉴와 Level 4 지도자 드래프트 이후 주사위 화면을 포함한다. 화면 크기 변경 후 레이아웃이 안정화된 상태의 보드칸 이름 경계, 버튼 가로 넘침, 보드 프레임, 중앙 가로 넘침을 검사했다.

- 상단 주사위 0개, 중앙 주사위 모듈 1개 유지.
- 기존 `node tests/dual-dice.cjs`, `node tests/header-dice.cjs` 통과. 일반/교육용 Level 3·4 스크립트 구문, 난수 경계·분포·분리, 저장 복원, 상단 렌더링 상태를 검사한다.
- `node --check responsive-board.js`, `git diff --check` 통과.
- 화면 크기 검사는 iframe 뷰포트로 수행했다. 실제 iPhone·Android·iPad 하드웨어 및 Safari에서의 직접 검증은 수행하지 않았다.
