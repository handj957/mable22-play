# 결과 체인 다양화 — 레벨별 적용 목록 (검토용)

작성: 2026-11-02 · 대상: Level 1~4 및 Beginning(교육판) Level 1~4

## 0. 공통 원칙
1. **체인 엔진(choice-chain.js v2)** — 항상 켜짐. 주사위 → 도착 칸 → 실제 일어난 일 → 실제 바뀐 지표를 그대로 표시. 순자산은 실제로 바뀐 때만 나타남. 변화가 없으면 "변화 없음".
2. **결과 주사위(result-dice.js)** — 기본 **꺼짐**. 주소 뒤 `?variety=1`로 켬(`?variety=0`으로 끔, 브라우저에 저장됨). 칸에 도착해 원래 처리가 끝난 뒤 d12를 한 번 더 굴림.

| 결과 주사위 | 구간 | 의미 |
|---|---|---|
| 1–2 | 대형 악재 | 큰 손실/하락 |
| 3–4 | 소형 악재 | 작은 손실/하락 |
| 5–8 | 변화 없음 | 원래 칸 효과만 (확률 4/12) |
| 9–10 | 소형 호재 | 작은 이득/상승 |
| 11–12 | 대형 호재 | 큰 이득/상승 |

악재 1/3, 호재 1/3, 무변화 1/3 → 장기 기대값 중립(금액은 호재가 악재와 같거나 약간 큼).
3. 표시: 체인에 `🎲 결과 N` 이 원인으로, 효과 한 줄과 바뀐 지표가 함께 나옴.
4. 균형 검증은 AI 시뮬레이션을 하지 않았음 → 숫자는 **검토 후 조정 대상**.

## 5. Beginning(교육판)
Level 1~4와 같은 파일 구조이므로 같은 표가 적용됨. 교육용 문구 톤은 검토 후 별도 조정 가능.

## 6. 검토 요청 포인트
1. 금액/증감 크기(특히 대호·대악)가 적절한지
2. 무변화 비율(1/3)이 적절한지
3. 제외 칸 목록
4. 기본 ON 전환 시점
