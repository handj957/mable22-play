# Level 3·4 상단 주사위 중복 수정 (2026-10-31)

## 원인
두 레벨의 renderHStage()가 상단 #hwho 안에 dualDiceHTML(k)를 삽입했다. 보드 중앙 행동 패널도 동일한 주사위 쌍을 렌더링하므로 이동·판정 결과가 두 위치에 나타났다. 좁은 이름 카드에 주사위가 추가되어 상단 공간도 침범했다.

## 수정
상단의 주사위 컴포넌트 생성과 별도 판정 숫자 출력을 제거했다. 이름과 현재 진행 상태만 표시하며, 상단 정보 접기·펼치기 버튼은 유지한다. 보드 중앙의 이동·판정 주사위, 난수 생성, 이동 거리 및 판정 결과 저장은 그대로 사용한다.

## 검증
- 기존 tests/dual-dice.cjs 전체 통과: 일반/교육용 Level 3·4 구문, 이동 경로, 단일 추첨, 경계값, 균등 분포, 채널 분리, 저장 복원.
- tests/header-dice.cjs 통과: 두 레벨의 대기·선택·이동·도착·AI·파산 상태에서 상단 주사위 생성 금지, 게임 상태 변경 없음, 이름 이스케이프.
- Chrome 반응형 iframe에서 두 레벨을 393×852, 852×393, 820×1180, 1180×820 크기로 실행. 8개 조합 모두 #hwho .dual-dice 0개, .center .dual-dice 1개 확인.
- 두 레벨에서 게임 시작, 상단 접기·펼치기, 이동 주사위 클릭 이후 중복 없음 확인. Level 4 지도자 드래프트 이후에도 동일.
- 실제 iOS/Android 기기에서의 직접 실행 검증은 수행하지 않았다.
